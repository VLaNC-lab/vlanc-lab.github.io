# Essentials of Data Science Materials

Use this folder as the public asset root for the Essentials of Data Science course page.

- `Syllabus`: final syllabus PDFs or editable documents.
- `Lectures`: class PPT, PPTX, PDF, or Keynote decks. These appear in the Class PPTs section automatically.
- `Class-notes`: notes, handouts, and in-class worksheets.
- `Books`: public book PDFs or EPUB files only when redistribution is allowed.
- `Assignments`: assignment PDFs, notebooks, and starter archives.
- `Datasets`: small course datasets. Move large datasets to R2 or another asset host.
- `Resources`: extra notebooks, references, datasets, and project support files.

Keep filenames readable, for example `Module-01-Data-Science-Workflow.pptx`.
